闲鱼平台规则体检

📋 闲鱼平台规则速查（发布前过一遍，点开看全文）
红线（碰到就下架/封号）
① 禁止站外引流：标题、描述、图片、昵称里都不能留微信号/QQ/手机号/抖音号，也不能说「看主页」「私聊我」——所以搬家时图里的二维码、联系方式必须抹掉，文案里的联系方式必须去掉。
② 禁止售假：「高仿 / 精仿 / A货 / 复刻 / 原单 / 尾单 / 1:1」这些词是售假红线，品牌方投诉直接扣分；品牌词本身可以带（自用闲置正品），但别用来背书夸宣传。
③ 禁售限售类目：食品药品保健品、医疗器械、发票票据、账号出租出售、代写代考、外挂代练、动植物保护制品等，别发。
④ 禁止绝对化用语：「最好 / 第一 / 顶级 / 全网最低 / 100%」等广告法禁用语。

高频扣分点（搬家场景尤其注意）
⑤ 重复铺货：同图同文在多个号/多次发布，会被限流、下架甚至封号——所以每件都要改写文案（不是同义词替换），图片要抹码去水印。
⑥ 描述要真实完整：空描述、描述与实物不符可被投诉「货不对板」；成色、瑕疵要写明。
⑦ 类目要放对：错放类目会被下架（发布页已带类目兜底重试）。
⑧ 价格别异常：0 元 / 明显低价会被判低价引流。
⑨ 发布节奏：写操作限速 1 件/分钟，连发易触发风控（发布页已带护栏，别手动绕）。
⑩ 图片规范：首图别带大面积水印、促销贴纸、拼图；扫出过二维码/联系方式/面单的图必须处理后再生效。
