闲鱼搬家用工具包 · 使用说明
================================================================
整个文件夹可以直接复制到任何电脑、改名、换盘符、放 U 盘。
程序里没有任何写死的用户名、工作区目录或 C 盘绝对路径。

根目录一览：
  启动工作台.cmd   ← 双击它，浏览器自动打开本地工作台（唯一入口）
  使用说明.txt     ← 就是本文件
  AGENT_GUIDE.md   ← 给 AI 助手读的部署操作指南（见下）
  README.md / README_EN.md   ← 项目介绍（GitHub 用，纯净版里没有）
其余程序都在 app\ 里，数据都在 数据\ 里，不用手动碰。


一、第一次在新电脑上用（只需做一次）
----------------------------------------------------------------
方式 1（最省事）：把 AGENT_GUIDE.md 交给任何 AI 助手（Claude /
   ChatGPT / WorkBuddy…），它读完就知道怎么装 Python、装依赖、
   启动、验证，全部替你做。文档里也写明了 AI 不能碰的红线
   （登录态不外传、发布需你确认等）。

方式 2（自己动手）：
1. 装 Python 3.9+（python.org，勾「Add python.exe to PATH」）。
   也可以跳过这步：直接双击「启动工作台.cmd」，启动器按
   runtime\ → .workbuddy → 系统 PATH 的顺序找 Python，全都没有
   时会问你是否**自动下载便携版 Python（约 12 MB，需联网）**，
   选 Y 等它装好即可。
2. 双击「启动工作台.cmd」→ 浏览器自动打开 127.0.0.1:8765。
3. 停在第 1 页「环境准备」：缺什么一目了然，
   点「一键安装依赖」联网装一次（playwright / opencv /
   numpy / pillow / RapidOCR / openpyxl），装完自动重检，
   全绿就能进下一步。不用敲任何命令。

之后每天的流程就是网页里的四页：导出 → 清洗 → 发布。


二、网页四步怎么用（都在工作台里点）
----------------------------------------------------------------
第 2 页 导出包 / 换号
  一个闲鱼号 = 一个项目。点「一键导出新号商品」→ 弹出独立
  Edge 窗口 → 登录要导的号（首次扫码，之后免扫）→ 自动抓
  商品、下图、打包 ZIP 进收件箱 → 上方下拉选它「导入并切换」。
  也可以用忙鱼导出的 ZIP 放进 数据\收件箱\ 再导入。
  · 导出件数多时别关弹出的 Edge 窗口，跑完才生成 ZIP。
  · 遇到滑块请在窗口里人工过一下，脚本不绕风控。
  · 各号的状态、改动、发布包完全隔离，项目列表随时切换。

第 3 页 清洗与改写
  1) 一键自动重写文案：把原标题拆成品牌/型号/规格/成色，
     重新组织成结构、句式、段落都不同的标题和描述。
     本地规则引擎，不联网、不调大模型；医用/成人/功效类
     高危品直接拒写。可看「改写对照表」，可单件重写/还原。
  2) 一键智能清洗：二维码→抹除、条形码→抹除、快递面单→
     整张删除、平台水印→裁边；品牌商标不处理。
     「看清洗效果」并排对比；真正改图发生在生成发布包时，
     原图和原始 ZIP 永不修改。
  3) 规则体检：按闲鱼平台规则逐件扫风险点（站外引流、
     售假词、绝对化用语、重复铺货、图片没清洗等），
     高危红色、提醒黄色，页面上有平台规则速查全文。
  4) 逐件核对后点「生成发布包」→ 进第 4 页。

第 4 页 发布
  · 默认演练，不发真实请求；真实发布要勾选确认。
  · goofish-cli 没装的话，页面里有「一键安装」和
    「扫码登录（弹浏览器）」，不用手敲命令。
  · 商品清单可勾选要发的件、可预览、可修改单件信息；
    已发布的标〔已发布〕，发布完标记自动刷新，不会重复发。
  · 失败自动跳过继续发（限速会自动等待重试、类目失败自动
    换兜底类目），连败 5 件才停。
  · 护栏：写操作限速 1 件/分钟、发布后回读核对。


三、文件都在哪
----------------------------------------------------------------
工具包根/
  启动工作台.cmd          唯一入口
  使用说明.txt            本文件
  AGENT_GUIDE.md          给 AI 助手读的部署操作指南（中英双语）
  README.md / README_EN.md  项目介绍（GitHub 页面用）
  config.json             数据目录 / 端口配置（可改，也可不动）
  app/                    全部程序
    workbench.py          工作台后端（含自检、装依赖、导出、发布）
    export_items.py       自导出器（工作台第 2 页调用）
    rewrite_engine.py     离线文案改写引擎
    qr_login_shim.py      扫码登录的 Edge 桥接
    index.html            工作台页面
    requirements.txt      依赖清单（第 1 页「一键安装依赖」用它）
    参考/                 A 号人工决策表（老项目复用）
  数据/
    收件箱/               导出 ZIP 与忙鱼 ZIP 都放这里
    项目/                 解压后的导出包、状态文件、扫描结果
    发布包/               一商品一文件夹 + publish_all.py + 清单
    浏览器资料/           Edge 独立资料目录（见第五节安全提醒）
    工作台项目.json       项目台账（只存 id，不存绝对路径）
    工作台日志.txt

发布的 ZIP、导入的 ZIP、生成结果全在工具包里，拷走文件夹就全带走。


四、数据路径可以改（两种方式，任选）
----------------------------------------------------------------
方式 A：工作台第 2 页「数据放在哪」，填路径 → 点「应用并重载」。
方式 B：改根目录 config.json 里的 data_dir，改完重启工作台。

  "data_dir": "数据"              → 跟着工具包走（默认）
  "data_dir": "D:\\闲鱼数据"      → 数据单独放 D 盘
  "data_dir": "U:\\xianyu-data"   → 数据放 U 盘

相对路径以工具包根目录为基准；绝对路径直接生效。
JSON 里的反斜杠要写两个。切换位置只换存放地点，不删除任何文件。


五、安全与风控（别跳过）
----------------------------------------------------------------
· 数据/浏览器资料/ 是 Edge 独立资料目录，可能含闲鱼登录态。
  换电脑时不要连它一起外传；新电脑会自动新建空目录，重新扫码。
· 导出器只导当前登录的自有账号，只读两个 mtop 响应，不搜索
  他人商品、不伪造设备、不绕滑块。遇 RGV587 / 滑块会停下。
· 读接口也是慢跑（默认 2.5 秒/件）。刚弹过滑块的风控窗口里
  别全量拉。
· 真实发布装 goofish-cli 后才有；护栏 1 件/分钟、失败即停、
  发布后回读核对。发货方式默认取商品原物流，可在每件抽屉里
  改「无需邮寄 / 一口价 / 按距离计费」。
· 新导入的号默认「一件都不纳入」，文案是原号原文，跨号发布前
  必须重写标题和描述，否则同图同文会被判重复铺货。
· 自动重写只是把已知事实重新组织，不保证合规：图片、类目、
  标题仍要人工过一遍；被判「放弃」的商品不要放行。
· 所有数据只落本机，不上传任何服务器。


六、常见问题
----------------------------------------------------------------
· 双击 .cmd 报乱码：.cmd 内容是纯 ASCII，正常不会乱码。
  别用记事本把 .cmd 另存成 UTF-8（带不带 BOM 都会出问题）。
· 找不到 Python：装 Python 并勾 PATH；或设环境变量
  XIANYU_PYTHON = python.exe 的完整路径（不带引号）；或在
  工具包里建 runtime\ 目录放一个便携版 python.exe。
  启动器按 runtime\ → .workbuddy → 系统 PATH 的顺序找。
· 端口被占：启动器会先清掉占着 8765 的旧进程；工作台本身
  还会自动往后试 8765–8774。
· 「一键智能清洗」显示「调整 0 张」：初始导入时动作已按同一
  套规则排好，所以常是 0，不是没生效；看「看清洗效果」核对。
· 想清空重来：删掉 数据\ 里 项目/、发布包/、收件箱/ 的内容
  即可，程序部分不用动；或直接用一份全新的工具包拷贝。
· 换电脑后老项目还在：台账里带的是历史商品数据，可正常查看；
  不想带就删掉 数据\项目\ 下对应文件夹，工作台会跳过它。
